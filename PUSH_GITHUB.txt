把项目上传到 GitHub 的命令模板

先打开 PowerShell，进入项目目录：

cd C:\Users\huanghc\Downloads\a-share-analyzer

然后执行：

git init
git add .
git commit -m "init a-share analyzer"
git branch -M main
git remote add origin 你的GitHub仓库地址
git push -u origin main

例子：

git remote add origin https://github.com/你的用户名/a-share-analyzer.git

如果提示没有登录 GitHub：
1. 按提示登录
2. 或使用 GitHub Desktop 上传
